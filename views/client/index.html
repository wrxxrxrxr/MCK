Общая информация

1 О личном кабинете
Личный кабинет клиента МСК-Релайбл позволяет отслеживать статус заказов, ход выполнения работ, скачивать документы и оставлять отзывы.
2 Навигация
☰ Кнопка меню — открыть/закрыть боковое меню
🔔 Колокольчик — включить/отключить push-уведомления
Выйти — выход из личного кабинета

Разделы кабинета

1 Главная
Обзорная страница со статистикой:
• Всего заказов
• В работе
• Завершено
• Отзывов
2 Мои заказы
Список всех ваших заказов с информацией о статусе и стоимости. Для завершенных заказов доступна кнопка "★ Оставить отзыв".
3 Ход работ
Детальная информация о выполнении работ:
• Прогресс по объекту в процентах
• Перечень работ с возможностью раскрыть детали
• Комментарии от менеджера
• Прикрепленные файлы и фото
4 Документы
Все документы по вашим заказам: договоры, сметы, акты. Доступно скачивание .
5 Профиль
Ваши личные данные: ФИО, Email, телефон. Кнопка "Сменить пароль" позволяет изменить пароль для входа.

Работа с разделом "Ход работ"

1 Выбор заказа
Если у вас несколько активных заказов, вверху страницы появятся вкладки для переключения между объектами.
2 Просмотр работ
Нажмите на любую работу или кнопку "▼" чтобы раскрыть детали:
• Количество и сроки
• Исполнитель
• Комментарии по работе
• Прикрепленные файлы и фото
3 Файлы и фото
Фотографии с объекта можно открыть для просмотра или скачать. Документы доступны для скачивания по клику на название или кнопку "⬇ Скачать".

⭐ Как оставить отзыв

1 Условия
Отзыв можно оставить только для завершенных заказов, по которым еще нет отзыва.
2 Процесс
1. Перейдите в раздел "Мои заказы"
2. Найдите завершенный заказ
3. Нажмите кнопку "★ Оставить отзыв"
4. Выберите оценку (1-5 звезд)
5. Напишите текст отзыва
6. Нажмите "Отправить отзыв"
Отзыв появится на сайте после проверки модератором.

🔔 Push-уведомления

1 Включение
Нажмите на иконку 🔔 в шапке. При первом включении браузер запросит разрешение на отправку уведомлений — нажмите "Разрешить".
2 Какие уведомления приходят
• Изменение статуса заказа
• Новые комментарии менеджера
• Завершение этапов работ
• Добавление новых документов
3 Отключение
Повторно нажмите на 🔔 чтобы отключить уведомления.

Частые вопросы

Как скачать договор?
Перейдите в раздел "Документы" и нажмите кнопку напротив нужного файла.
Как изменить контактные данные?
Свяжитесь с менеджером — контакты указаны в разделе "Профиль".
Забыл пароль?
На странице входа нажмите "Забыли пароль?" и следуйте инструкции.
